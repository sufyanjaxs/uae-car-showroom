# User Manual - UAE Car Showroom Management System

## Getting Started

### Login
1. Open your browser and navigate to the system URL
2. Enter your email and password
3. Click "Login" or press Enter
4. If MFA is enabled, enter your verification code

### Dashboard Overview
After logging in, you'll see the main dashboard with:
- **Navigation Sidebar** (left): Access all modules
- **Header** (top): Search bar, language toggle, notifications
- **Main Content**: Role-specific widgets and shortcuts

## Module Guides

### 1. Inventory Management

**Viewing Vehicles:**
- Go to "Inventory" in the sidebar
- Use the search bar to find vehicles by VIN, chassis, or plate
- Apply filters for status, condition, price range
- Click on any vehicle to view full details

**Adding a Vehicle:**
1. Click "Add Vehicle" button
2. Fill in VIN (required), model, trim, color
3. Enter purchase details, documents, and features
4. Upload images (drag & drop supported)
5. Click "Save"

**Vehicle Details Page:**
- VIN, chassis, engine numbers
- Model specifications
- 360-degree image gallery
- Service history timeline
- Ownership documents
- Pricing and profit calculations

**Transferring Inventory:**
- Select vehicle(s) and click "Transfer"
- Choose source and destination branches
- Add transfer notes
- Track transfer status

### 2. Sales Pipeline

**Managing Leads:**
- View all leads in pipeline view
- Filter by status, source, priority
- Click lead to see full profile
- Update lead status as it progresses
- Log communication history

**Creating Quotations:**
- Select customer and vehicle
- Add discounts (percentage or fixed)
- System auto-calculates VAT
- Generate PDF quotation
- Email directly to customer

**Processing Sales:**
1. Convert qualified lead to opportunity
2. Schedule test drive
3. Negotiate and create quotation
4. On acceptance, create sales contract
5. Process payment/deposit
6. Complete delivery checklist

### 3. CRM

**Customer Management:**
- View all customers in card or table view
- Search by name, phone, email, Emirates ID
- Click customer for 360-degree view
- View purchase history, interactions, timeline
- Segment customers for marketing

**Logging Interactions:**
- Record calls, emails, WhatsApp messages
- Log meeting notes and outcomes
- System timestamps all interactions
- AI sentiment analysis on communications
- Automatic timeline updates

### 4. Finance & Accounting

**Creating Invoices:**
- Select sales contract or service order
- Line items auto-populate
- VAT calculated at 5%
- Choose payment terms
- Send invoice via email

**Recording Payments:**
- Enter payment amount and method
- System updates invoice status
- Receipt generated automatically
- Real-time balance tracking

**Loan Applications:**
- Submit customer financing requests
- System calculates EMI
- Track bank approval status
- Upload required documents

**VAT Reports:**
- Automated VAT calculation on all transactions
- Quarterly VAT return preparation
- Export to FTA-compliant format

### 5. Service & Workshop

**Scheduling Appointments:**
- Select customer and vehicle
- Choose service type
- Assign technician
- Set appointment time
- Send confirmation

**Managing Repairs:**
- Create repair order from service appointment
- Technician diagnosis entry
- Parts requisition from inventory
- Labor time tracking
- Digital inspection reports

### 6. Reporting

**Available Reports:**
- Sales Performance
- Inventory Status
- Customer Analytics
- Financial Summary
- VAT Reports
- Employee Performance
- Custom Report Builder

**Exporting:**
- All reports exportable to PDF, Excel, CSV
- Scheduled report delivery via email
- Dashboard snapshots
